# CLT-007 — Dependency-directed adaptive navigation

A source-qualified learner acquires selected full-state transition observations, fits local Boolean ANFs of degree <=2, asks for an independently derived counterexample on failure, and follows the resulting dependencies. It receives only the physical observer coordinate, never the hidden coordinate permutation or source coefficients. The checker has a declared exact source program; this is a synthetic authority contract, not authenticated source evidence. A cubic counterexample refuses the bounded acquisition language.

The interpreter derives reachability in the learned dependency graph. If all local maps are affine, it uses homogeneous GF(2) matrix powering. Otherwise it finds the observer's strongly connected component and its upstream driver, verifies the driver is closed, and for a small sink (<=8 coordinates) forms a conditional phase plan. Find the actual driver preperiod and cycle for the requested anchor, then compose the sink's one-period transformation over its finite local state space. Power that table by squaring and realize the residual phase. Reuse the plan for other starts with the same driver anchor. When the structural conditions do not match, use bounded direct orbit navigation. The policy does not know fixture type. No universal completeness or optimal route claim. Budget exhaustion returns UNRESOLVED with no partial answer. No budget escalation.

The source shape for each fixture is concealed by seeded coordinate permutations. Affine long-horizon results use an independent GF(2) polynomial multiplication oracle; nonlinear results use direct raw-source cycle indexing, separate from discovered-law execution. All exact outputs are checked on the retained coordinates, not just the requested bit. A separate 257-step direct check challenges every source with acquired closure. The comparison is a forced direct-cycle run using the same learned laws and the same total work allowance, not a deliberately slow full simulation. Discovery is charged to both. Graph scans, local monomial tests, measured state queries/cache accesses, table composition and matrix row combination are charged as abstract units; source implementation cost, sorting, allocation, hashing, bit complexity and independent oracle cost are not fully priced. Declared source verification and discovery are not free; the meter is not wall-clock or a complete machine-cost measure.

Read results.json for executed controls. CLT-006's BDD obstruction motivated the new route; this is a separate experiment, not a patch to the previous proposal. Source authority and proof portability remain future integration with existing VL-I authenticated inquiry, VL-64 navigation and E-CPU. No pretrained-model or general complexity-class result.
