# CLT-008 — Retained trajectory Grounds

A failed navigation may still acquire a valid interval of the source trajectory. Preserve its exact transitions rather than discarding them with the unresolved intention. Each distinct observed/computed state has an address (segment,offset); a segment is an ordered list of states with an optional verified tail edge into another segment. An open segment certifies only its acquired interval. A lookup inside a segment moves to another offset directly, without replaying the intervening source operations. At a tail, extend using the qualified transition law or follow the retained edge. Repeated identical boundary state yields a cycle and permits exact modular time reduction. Non-injective merging and cross-segment cycles are included in controls.

This experiment re-implements CLT-007's sparse degree-two local interpolation on its strongly coupled 24-bit fixture, with two concealed coordinate permutations. The synthetic independent symbolic checker has the declared exact source law; no source authentication is implied. The learned law is admitted relative to that contract. The independent post-run audit checks every retained edge against separately implemented source transitions and every completed answer against raw-source orbit indexing. A changed law gets fresh memory; equality of serialized learned laws is not a cryptographic source identity, and an enforced external admission API is future work.

The first batch uses the same 16 anchors and 10^12+39 horizon as CLT-007, with 300,000 charged units including discovery. Round-robin slices prevent a single long orbit monopolizing the batch. A matched baseline has identical scheduling, discovery charge and logical state-record cap, and retains each request's own cycle prefix, but does not share across requests. Completed partial-batch results are individually checked; unresolved queries never yield a predicted answer. A second 12,000-unit batch requests 64-step navigation from eight points deliberately selected from the failed long intention's acquired trajectory, not random global queries. Their coordinates are constructed independently from direct source steps outside the navigation meter; this is a targeted reuse experiment, not a free method of finding arbitrary useful anchors. Prior work and memory are retained by both routes; the baseline does not have cross-query lookup. Logical cap counts stored state records, not bytes; per-route overhead differs. No eviction. Counts charge selected control, state lookup, new transition evaluation and insertion, not complete runtime, allocation, hash or bit complexity. Independent replay and synthetic source/fixture setup are separately scoped. The first batch and warm followup have distinct declared allowances, not retroactive budget escalation of the unresolved trillion-step query.

The experiment demonstrates when failed work is a reusable interval Ground, not a method for solving arbitrary long orbits. A long trajectory with no shared suffix/interval may be expensive to store and not worth retaining. Future: cost-aware admission/eviction, persist source-qualified segments and receipts across E-CPU hosts, route selection based on overlap and marginal utility, symbolic invariants for the still unresolved orbit. Reproduce with `node experiments/retained_trajectory_grounds/clt008.js`; CI compares exact saved JSON. Prior: https://github.com/Kier73/VL-I/pull/81. No native or pretrained execution claim.
