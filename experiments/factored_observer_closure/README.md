# CLT-006 — Factored observer dependency closure

A failure of linear feature closure directs a different representation: retain physical coordinate functions sufficient to evaluate the observer and each selected transition. Discover exact local Boolean polynomials using degree-1 then degree-2 interpolation; an independent declared source-program checker validates each hypothesis and supplies a counterexample. Follow only the dependencies of verified polynomials. State labels are independently permuted for each fixture; the learner receives the physical observer coordinate, not the coordinate permutation. The cache counts unique full-state transition responses; scalar extraction/interpolation work is separate.

This is exact coordinate dependency closure, not minimal arbitrary observer quotient. Local function equality plus closure proves that the selected state variables suffice under all action words. Source qualification is synthetic: a declared program is authoritative by construction; sparse samples alone cannot exclude a higher-degree hidden term.

Construct shared reduced ordered Boolean decision diagrams with a fixed physical variable order, hash-consing, memoized if-then-else and substitution. Compose the action block and power it by binary composition. No expansion into the entire linear pullback basis is required. Count allocated and live decision nodes separately, and charge recursive ITE/node/substitution calls under a bounded budget. No optimal variable order, polynomial closure or universal speedup is claimed. Compare with an independent direct source-cycle oracle, reporting its action evaluations, not claiming equal costs for different operation units. Source input domain and rotation/shear/coupling use the CLT-005 family with concealed coordinate labels; 10-bit cases are exhaustively tested, 14/20-bit cases use 128 deterministic source coordinates. The source-program check proves local pullbacks on the full declared cube, whereas the independent tests challenge implementation correctness. An explicit low-node-budget test refuses; no fallback result is fabricated.

Reproduce with `node experiments/factored_observer_closure/clt006.js`. The same function executed before commit; CI checks the saved JSON. This is a standalone experiment outside the VL-I core, not a trained-model or native runtime result. Public antecedent: [CLT-005](https://github.com/Kier73/VL-I/pull/79).
