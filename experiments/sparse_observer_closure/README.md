# CLT-005 — Sparse nonlinear observer closure

CLT-004 constructed the linear span of finite observer pullbacks from complete tables. Here a learner acquires only selected state-transition results from an oracle and discovers Boolean polynomial pullbacks (algebraic normal form, ANF). A separate symbolic checker has a declared exact source program; it never supplies the polynomial to the learner. It returns pass or a counterexample coordinate. Source program and actual fixture evaluation are separately written and tested exhaustively afterward. This is a synthetic source-qualified construction, not authenticated sensor authority.

For degree d, the points of Hamming weight at most d determine every degree-at-most-d ANF by triangular interpolation. The learner increases degree when the checker rejects and queries the counterexample. It retains the source response cache across all pullbacks. The checker substitutes the source coordinate polynomials using Boolean-ring multiplication (monomial union, XOR cancellation); exact equality of ANF proves the pullback on the entire declared Boolean cube. A nonzero discrepancy yields a minimum-degree monomial mask that is itself a separating input. These are standard Boolean-polynomial operations.

Independent post-discovery tests compare encoded transitions at every state and long-horizon observation at 10^12+39 repetitions using a separate cycle oracle. The full-domain audit is reported separately, not counted as sparse discovery. Verifier work includes monomial product counts but excludes all other computation and representation costs. A source program independently known to be authoritative is necessary to substitute symbolic checking for measurement; this fixture provides that program by construction. Without it, the high-degree hidden-monomial control demonstrates that low-degree samples cannot prove arbitrary source equivalence. Rank/degree budget returns UNRESOLVED.

The 10-bit source has four visible coordinates and six rotating nuisance coordinates. Rotation, nonlinear shear and hidden coupling progressively enlarge the pullback algebra. Unlike CLT-004, the nuisance rotation lets a coupled observer access additional formerly hidden coordinates. See results.json for actual standalone execution. This JS experiment is outside VL-I's runtime package; no native trained-model integration or speedup is claimed. Native connection points: ACT-001's signed observation receipts, TDL-002's row representation, SHAPE-010's counterexample-based expansion, and VL-64 monoid powering. The next step is a source-program-qualified native implementation with cost selection between symbolic, table and cycle realization.
