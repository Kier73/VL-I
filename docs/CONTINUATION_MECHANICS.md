# From an addressable head to a continuing decoder

E-CPU provides a useful starting point. Its layer handoff persists the hidden tensor and binds it to the model, layer coordinate, predecessor and native receipt. A worker resumes by checking the externally retained head and retrieving the bytes. This solves a transport problem for a layer boundary. To generate another token, the receiving worker must also recover every layer's prefix-dependent state, or have a way to reconstruct precisely the part of it that the next operation needs. [E-CPU handoff implementation](https://github.com/Kier73/E-CPU/blob/d329b8ca6d1f9c94f77e7823a3352cbe66b34707/mailcpu/model_orbit_handoff.py)

## A checked obligation and a measured failure

Let π encode a decoder state. If updating the encoded state on token a gives exactly π(step(s,a)), and decoding the resulting observation agrees with the reference readout, induction gives agreement after every finite token suffix. The Lean proof works for arbitrary deterministic state and token types. Establishing these two hypotheses for a concrete model remains the work of the implementation. Numerical tolerances require a separate error-propagation argument. [Lean source](../formal/Continuation.lean)

On the previously verified Qwen head archive, histories [1761,628] and [1761,33303] both gave bin 3 under round(10000 × row contribution). Appending token 628 gave bins −11 and −9. Thus a deterministic update that sees just this bin and the next token cannot preserve even the binned observation for these histories. The original floating-point outputs already differed before binning. This counterexample rejects one candidate summary and establishes no general lower bound on state size. ## The shortest test toward generation

1. **Compose one row.** On the same held-out prefix, sum all 48 layer-zero head contributions to the same projection row. Compare with the dense attention branch before residual addition. Share embedding and normalization reads across heads and count physical reads separately from logical requests.
2. **Cross a real dependency.** Form the complete residual vector, apply the trained feed-forward block, and feed that vector into layer one. Token-indexed projections are reusable at layer zero because its input is an embedding. The same token can have different hidden inputs at layer one. Reuse the existing indexed Qwen layer-chain machinery as the comparison path. [Existing architecture-directed decoder](QUALIFIED_ARCHITECTURE_DIRECTED_DECODER.md)
3. **Close the generation loop.** At every recurrent layer retain convolution history plus a qualified recurrent representation. At each full-attention layer retain positions and KV data or a verified substitute. Finish normalization and vocabulary projection, choose the greedy ID with a declared tie rule, serialize the continuation, and append that ID in a fresh process. Compare both logit vectors and both IDs with a pinned reference. Measure cold compilation, per-token arithmetic, network traffic, state size and restart cost.

The decisive milestone is the second generated token after restart. The first checks a forward pass. The second also tests whether the representation carried the trained dynamics across the generation boundary.
