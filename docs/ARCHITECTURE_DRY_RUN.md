# Where the current VL stops on other architectures

On November 24, 2026, the released external interpreter was challenged with **3,636 registrations from four pinned catalogues**. Three reached a trained operand request. The other 3,633 stopped earlier. A separate replay verified the original descriptor bytes of all **673 distinct pinned public witnesses** in VL-I’s earlier discovery survey. These populations overlap. Neither test supplied any trained payload bytes. [Registry results](../experiments/architecture_survey/2026-11-24-dry-run/summary.json) · [Public witness results](../experiments/architecture_survey/2026-11-24-dry-run/public-descriptors.summary.json)

| Pinned catalogue | Enumeration unit | Probed | Reached a trained operand |
| --- | --- | ---: | ---: |
| Transformers | Distinct model-type and PyTorch auto-class pairs, plus registered config types without a mapped head | 1,762 | 3 |
| timm | Statically decorated model factories | 1,371 | 0 |
| Diffusers | Top-level classes ending in `Pipeline` in `pipeline_*.py` under the pipeline source tree | 296 | 0 |
| scikit-learn 1.6.1 | Entries returned by `all_estimators()`, including transformers and meta-estimators | 207 | 0 |

The Transformers rows span 822 model-type keys. The inventory includes aliases, task heads, component configs and model variants. A count of distinct mathematical architectures cannot be inferred from these totals. Custom repositories, other runtimes, dynamically registered third-party models and unenumerated graph formats remain outside this census. The target was the shipped 21,926-byte external interpreter shared by VL-I and VL-64. Separate Qwen research workers and the Llama decoder seed have different capabilities.

## Read the evidence

The runner imported the actual dispatcher and source readers from the released archive under isolated Python. For a registration-only probe, it supplied the fields available at registration and an explicitly empty Safetensors inventory. For a simulated pipeline or estimator layout it omitted the root transformer config. Those results locate the current discovery or dispatch boundary. They make no claim about the contents of an individual checkpoint. Nine control probes used real pinned model pages and real shard headers. The byte guard forwarded the eight-byte length and declared header only. It raised before forwarding the first trained range. Numerical qualification comes from the separate [text](EXTERNAL_ARCHITECTURE_INTERPRETER.md) and [vision](EXTERNAL_VISION.md) experiments.

One JSON object per registration records its source declaration, task or factory, exact exception or requested interval, and development category. Transformers records include forward arguments, direct constructor symbols and candidate primitives reachable within the same source file. timm records retain factory calls and declared model arguments. Diffusers records retain component names, call inputs and component calls. Estimator records include documented fitted state and available inference methods. These source-derived fields guide implementation review. Imported helpers, dynamic branches, inherited methods and third-party kernels still require inspection for the particular checkpoint. [Searchable inventory, JSONL](../experiments/architecture_survey/2026-11-24-dry-run/inventory.jsonl)

The second run fetched each public witness's actual descriptor and checked its SHA-256 against the earlier survey. For known dispatch pairs it also opened the real page and tensor inventory. Other probes used the observed descriptor and the empty tensor inventory, so early format failures on particular live shards remain untested there. Two witnesses reached a weight request, 671 were refused, and none remained unresolved. BAAI/bge-small-en-v1.5 reaching its embedding row establishes addressability of that operand only. Its whole-model behavior still needs independent qualification. [Per-checkpoint evidence](../experiments/architecture_survey/2026-11-24-dry-run/public-descriptors.jsonl)

## Development log

GitHub push protection flagged one public class identifier under `mistral3`. That row retains its pinned declaration link, exception type and refusal category. The literal identifier and verbatim error were omitted from the published record.

The table orders work by the smallest experiment that can distinguish a source-binding problem from a missing computational law. Each pass condition applies to a named output. Merely reaching a weight read does not close an item.

| Test case and observed first stop | Development needed | Acceptance test |
| --- | --- | --- |
| **Original GPT-2** requests `transformer.wte.weight`; its actual header has `wte.weight`. DistilGPT2 reaches a weight. | Bind the model root once from the inventory. Resolve the embedding, every learned block and final norm under that same root, including tied output weights. Reject mixed or ambiguous mappings. | Compare all logits and the next token on multiple prefixes from both roots. A renamed or mismatched block must fail before its output is accepted. |
| **timm ResNet-18** has a root `architecture` field; the dispatcher asks for `model_type`. | Translate the timm factory definition, preprocessing and state-dict roles into canonical convolution, norm, shortcut and head nodes. Check stem, downsampling and classifier variations before reusing existing operators. | Compare stem features, a resolution-changing block and all classifier logits against timm on the same pixels. Include a factory variant that should be refused. |
| **ResNet-50** passes the family and image-input checks but fails the ResNet-18 configuration check. | Implement bottleneck blocks with 1×1 reduction, 3×3 spatial convolution and 1×1 expansion. Bind stride placement, shortcut projection and stage depths from the checkpoint. | Compare each stage tensor and all classification scores for upright and rotated crops; retain the ResNet-18 regression. |
| **BERT/GPT-2/ResNet alternate heads**. Fourteen registered heads or base/backbone observations on the existing families lack a route. | Separate backbone outputs from the head program. For BERT masked LM bind the prediction transform, activation, norm, decoder and vocabulary bias. For classification and QA bind pooling or position selection, output width and task label order. For ResNet backbone expose the requested stage tensors. | For each head compare its entire named result with the upstream class. Test a changed mask or token position. A matching class decision alone misses transpositions and label-order errors. |
| **ViT** is refused at model/input dispatch. | Bind patch convolution, class token, position embeddings, attention, pre-norm residual blocks and the classification head. Specify crop and positional interpolation domains. | Compare patch embeddings, class-token state and all logits; include a patch-order perturbation. |
| **Whisper** is refused at dispatch. | Add an input contract for acoustic features, temporal convolution, encoder attention, causal decoder attention, encoder–decoder cross-attention and decoder-start tokens. Qualify waveform preprocessing separately if waveform input is offered. | On fixed log-mel features and decoder IDs compare encoder output, first-step logits and a second step with a changed decoder history. |
| **Mamba** is refused at dispatch. | Bind causal depthwise convolution, its history, the learned state-space parameters, selective recurrence and gated output projection. Define position and restart state. | Compare full-prefix evaluation with stepwise execution, then resume from a saved state and compare every next-token score. |
| **Stable Diffusion** fails on missing root `config.json`. The repository describes a component graph. | Read `model_index.json`; bind versioned component subdirectories, tokenizer, text encoder, denoiser, VAE and scheduler. Give latents, conditioning, timestep sequence, guidance and RNG explicit identities. | Fix initial latent and conditioning. Compare first denoiser output, scheduler update and final decoded tensor separately. For another pipeline bind the actual component list from its inventory row. |
| **Scikit-learn estimators** encounter the simulated standalone layout's missing root config. | Define a declarative fitted-state format. For linear classifiers bind feature order, coefficients, intercept and class ordering. For trees bind feature, threshold, children, missing-value policy and leaf scores. For ensembles bind child order and aggregation. For transforms define output shape and sparse semantics. Eighteen rows have none of the surveyed inference methods and first need an explicit requested observation. | Compare per-class scores or transformed values with the fitted estimator. For a tree test values exactly on and immediately to either side of a threshold. For a pipeline compare each transform before the final prediction. |

For the other 1,589 Transformers model/head rows, the inventory identifies the configuration, wrapper, task and source declarations to lower. For the 156 config-only rows, establish whether the type is an independently executable model or a nested component, identify its owning graph, and obtain a pinned trained fixture before implementing a dispatcher entry. For quantized or packed variants, qualify the stored dtype, block layout, scale/zero-point axes and byte intervals separately from the architectural equations. The current dry run only establishes the first reached blocker; later failures need a subsequent probe.

## Reproduce and inspect

Use the [tested archive](https://github.com/Kier73/VL-64/blob/46d58dd3f445de4e1f898e0d9f9c1e41d68b59d2/artifacts/VL64-external.pyz). Download each of the three GitHub source ZIPs listed under `pins` in the summary from `https://codeload.github.com/OWNER/REPO/zip/COMMIT` as `artifacts/dry-transformers.zip`, `artifacts/dry-timm.zip` and `artifacts/dry-diffusers.zip`. Generate the estimator catalogue with scikit-learn 1.6.1 installed. Only the exporter imports that library. Run the probes from VL-I with Python 3.13 and network access.

```sh
python examples/export_estimator_inventory.py artifacts/dry-sklearn.json
python -I -S examples/architecture_dry_run.py --seed ../VL-64/artifacts/VL64-external.pyz --archives artifacts --out artifacts/dry-results
python -I -S examples/public_descriptor_dry_run.py --seed ../VL-64/artifacts/VL64-external.pyz --survey experiments/architecture_survey/2026-11-22-public-descriptions.json --out artifacts/dry-results/public-descriptors.jsonl
```

For a particular architecture search the JSONL with a class name such as `WhisperForConditionalGeneration`, `StableDiffusionPipeline` or `DecisionTreeClassifier`. Use the declaration link and recorded arguments to choose the smallest observable operator for the next live test.
